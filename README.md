# QuickBite 🍕 - Full Stack Food Ordering Website

QuickBite is a modern full-stack food ordering web application that allows users to browse restaurants, explore food items, sign up/login, add items to cart, and place orders seamlessly.

---

# 🚀 Live Demo

🌐 Frontend Live Website:  
https://quickbite-varshith.netlify.app/

---

# 📌 Features

- User Signup & Login
- Restaurant Browsing
- Food Item Listings
- Add to Cart
- Order Management
- Responsive UI Design
- MongoDB Database Integration
- Backend API Integration
- Fast Food Delivery Style Interface

---

# 🛠️ Tech Stack

## Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Tailwind CSS

## Backend
- Node.js
- Express.js

## Database
- MongoDB Atlas

# ⚙️ Backend Setup

## Install Dependencies

```bash
npm install
```

## Create `.env`

```env
PORT=5001

EMAIL_USER=your_email@gmail.com

EMAIL_PASS=your_app_password

MONGODB_URI=your_mongodb_connection_string
```

## Run Backend

```bash
npm start
```
